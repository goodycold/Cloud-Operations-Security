# Cloud-Operations-Security
Cloud Operations and Security Practical Assessment


**ICDFA – Cloud Security Engineering Practical Laboratory Assessment**

## Project Overview

This project documents the practical implementation of cloud operations, administration and security exercises as part of the ICDFA CCSE-102 assessment.

The assessment focuses on cloud resource administration, access control, virtual machine management, network security, Linux system administration, storage protection, backup and recovery, monitoring, security assessment and remediation.

## Laboratory Environments

The practical exercises are conducted across two distinct environments:

### 1. Azure Administration Simulator

The ICDFA-provided Azure administration simulator is used to perform simulated cloud administration and security operations, including:

- Resource group creation, management and tagging.
- Governance and Role-Based Access Control (RBAC).
- Virtual machine administration and operational state evaluation.
- Network security rules and connectivity validation.
- Storage configuration and data exposure assessment.
- Monitoring, operational alerts and audit log analysis.

### 2. Linux Administration Environment

Actual Linux administration activities are performed within the configured Linux laboratory, including:

- Linux laboratory installation and configuration.
- HTTP service deployment and connectivity testing.
- File integrity verification using SHA-256.
- Backup creation and recovery verification.
- Linux command-line administration and system monitoring.

**Environment distinction:** Simulated Azure operations are clearly identified and documented separately from activities executed on the actual Linux system. Simulated operations are not presented as deployments on Microsoft's live Azure infrastructure.

## Project Objectives

- Demonstrate cloud resource administration and governance.
- Configure and validate administrative access permissions.
- Evaluate virtual machine operational states.
- Implement and test network security controls.
- Deploy and verify a functioning Linux HTTP service.
- Assess storage security and data exposure risks.
- Perform file integrity verification, backup and recovery.
- Analyse monitoring alerts and audit logs.
- Identify security misconfigurations and verify remediation.
- Prepare a professional Cloud Operations and Administration Security Assessment Report.
